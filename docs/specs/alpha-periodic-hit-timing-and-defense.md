# Alpha type 4 periodic buff hits

**FINAL / STABLE / HELD.** Independent static review of the original 32-bit Alpha client, 2026-11-22. The evidence is Cube.exe, 3,885,568 bytes, SHA-256 `84a7a132a84d4282338e7ea45a1940d32066d64e39cbafed8f2418d5a6dc30bf`, image base `0x400000`. All addresses below are RVAs for this image. Offsets refer to native objects or record payloads. Numeric field descriptions preserve distinctions whose in-game names were not established.

## Which updates produce hits

The pass visits the target's buff list at +0x1178 from first to last. Each entry contains a one-byte type at +0x00, a binary32 magnitude at +0x04, a signed 32-bit remaining time in milliseconds at +0x08 and a 64-bit source creature ID at +0x10. List links precede the entry payload. The pass first subtracts its signed 32-bit elapsed time from the entry's remaining time. A result of zero or less queues that entry for removal and skips all of its type-specific work. The queued entries are erased after the traversal, in collection order. RVAs 0x20C549–0x20C54F, 0x2120E2–0x212163, 0x2183FA–0x2184C2, 0x6F440, 0x68D30 and 0x860B0.

A surviving type 4 entry requires the world byte at +0xB4 to be zero. Divide the remaining time before and after the subtraction by 400, using signed integer quotients truncated toward zero. Different quotients produce exactly one call to the hit routine. Equal quotients produce none. There is no catch-up loop. Multiple qualifying entries each make their own call in list order. The caller finishes each hit, including immediate application, before visiting the next entry. The time bookkeeping still runs when the mode byte suppresses the hit. RVAs 0x21213B–0x212163, 0x218310–0x2183DF and 0x2183FA–0x218436.

| Remaining time before and after one update (ms) | Calls from that entry |
| --- | --- |
| 401 to 400 | 0 |
| 400 to 399 | 1 |
| 1,200 to 1 | 1 |
| 1,200 to 0 | 0, entry queued for removal |

A separate original hit with selector 0x11 can append a type 4 entry bearing the source ID, 3,000 ms and 0.1 times that original hit's final magnitude. The periodic call itself supplies selector zero. Starting at 3,000 ms, sufficiently small updates can therefore produce seven calls, crossing below 2,800, 2,400, 2,000, 1,600, 1,200, 800 and 400 ms. The buff's lifetime alone does not guarantee seven calls. RVAs 0x19804D–0x1981CB and 0x218371–0x2183DA.

## Inputs and immediate results

The caller looks up the entry's entire 64-bit source ID in the world creature map at the time of each hit. An absent key yields a null source and the call proceeds. The first creature argument is the buff bearer. The magnitude comes directly from the entry, with zero initial reaction probability, three zero vector components and the selector that chooses target defense RVA 0x467A0. The call also supplies the bearer's +0x1320 address, the current output collector and the caller's context. RVAs 0x2F000, 0x77D90 and 0x218362–0x2183DA.

For finite inputs, target HP at +0x16C at or below zero returns before records and random draws. With a source present, source action byte +0x68 equal to 0x5B or 0x4A also returns immediately if target +0x5C bit 0 is clear. A qualifying call therefore need not produce any record. RVAs 0x196D73–0x196DD3.

With the source absent, the hit routine consumes one discarded random draw, sets target binary32 +0x1184 to 0.5 and carries the supplied magnitude forward. This path bypasses source-dependent defense and reaction calculations. With a source present, the following decisions occur in order. RVAs 0x197E3D–0x197E5E and 0x1983EC–0x198402.

1. Source action 0x1C emits an effect using one random draw. If the path continues through normal defense, it later raises target +0x1184 to 0.3 when below 0.3. RVAs 0x196DD1–0x196EC1 and 0x197AC1–0x197AFF.
2. Target category byte +0x60 equal to 1, with either +0x124 bit 7 or +0x5C bit 5 set, takes a special exit. It draws once for a sound, appends one hit record of kind 3 with the full input magnitude, calls the record consumer and returns. This record bypasses the HP update. RVAs 0x196EC1–0x197016 and 0x195D70–0x195D74.
3. Otherwise sum the binary32 magnitudes of all type 6 entries on the target in list order. Divide the source's signed integer +0x70 by the integer from source helper RVA 0x44CB0, converting both to binary32 first. Cap the ratio above at 1, then subtract it from 1. This factor multiplies the type 6 sum. A strictly positive product emits a kind 5 hit with the **full original magnitude**, draws once for a sound and applies that record before continuing. Subtract the product from the input magnitude. A result at or below zero ends the hit here. With a nonpositive product, carry the input magnitude forward. RVAs 0x197235–0x197500.
4. Subtract the factor times the target defense returned by RVA 0x467A0, with the helper result rounded to binary32 before multiplication. Clamp negative results to zero. A result of zero can still produce an ordinary record. A separately computed, uncapped source ratio greater than 0.25 can produce equipment effects. The periodic call disables the adjacent equipment damage-bonus branch. RVAs 0x19750B–0x19768C, 0x1976D8 onward and 0x19A800.
5. For both present and absent sources, multiply the surviving magnitude by each type 1 magnitude on the target, in list order, rounding each multiplication to binary32. Both type 1 and type 6 scans inspect entries by type without checking remaining duration. An entry already queued for removal can therefore still affect a later hit in the same pass. The periodic call has no intrinsic critical roll or random magnitude multiplier. RVAs 0x198023–0x1980B8, 0x197235–0x197267 and 0x21843C–0x2184C2.

## Defense inputs

The source divisor at RVA 0x44CB0 is the source's binary32 +0x17C times a multiplier, truncated toward zero to a signed integer. For +0xAA8 equal to 3, subtype byte +0xAA9 selects 60 for 6, 80 for 8, 20 for 11, 12, 15, 16 or 17, and 50 otherwise. In other categories +0x7E bit 4 selects 20 when set and 50 otherwise. The normal finite arithmetic described here assumes a nonzero divisor.

For the target defense calculation, the level fraction at level L is one minus the reciprocal of one plus 0.05 times (L minus one). RVA 0x467A0 evaluates it at target signed level +0x190. The level scale is two raised to three times this fraction. The rank scale is two raised to 0.25 times the unsigned byte at +0x1A8. Each exponent is formed in binary32 and exponentiation uses binary64 with its result rounded to binary32. Multiply the rank and level scales for the combined scale. The base defense is target binary32 +0x188 times the combined scale. For category +0x60 equal to zero, use two times the level scale, then multiply by +0x188. In either case add the combined scale when target +0x7E bit 5 is set. RVAs 0x467A0–0x46894.

Add matching equipment contributions in this order: item +0x530 of type 4, +0x648 of type 6, +0x760 of type 5, +0x878 of type 7. For each item use its signed level at +0x10 plus 0.1 times its signed integer at +0x114 as L in the same level-scale calculation. Multiply that level scale by two raised to 0.25 times the unsigned item byte at +0x0C. Multiply the result by the item's factor, initially 1 for type 4 and 0.5 for the other three. Material byte +0x0D multiplies the factor by 0.85 for 1 or 19, or by 0.75 for 26 or 27. Other values preserve it. The arithmetic between exponentiations, including successive additions, uses binary32. RVAs 0x46894–0x46941, 0xC7AF0–0xC7BA8 and 0x45F60–0x45FE5.

## Ordinary hit record and reaction draw

The hit payload carries the resolved source creature's 64-bit ID at +0x00 (zero for an absent source), target ID at +0x08 and final binary32 magnitude at +0x10. For an ordinary periodic hit, byte +0x14 is zero, signed duration +0x18 initially zero, +0x1C zero, and +0x20, +0x28 and +0x30 are the target's three signed 64-bit position components from +0x10, +0x18 and +0x20. The three binary32 vector components at +0x38, +0x3C and +0x40 start at zero. Byte +0x44 and kind byte +0x45 are zero. Byte +0x46 is one for source action 0x1C and zero otherwise. The two special kinds use their indicated kind, full input magnitude, resolved IDs, target position and otherwise zero initialized fields. Padding has no specified value. RVAs 0x59A30, 0x599A0, 0x196F46–0x196FEE, 0x1972F8–0x1973FA, 0x197FA8–0x1980B8 and 0x198658–0x198677.

The ordinary reaction test requires a resolved source, a target signed timer at +0x12C strictly below -3,000 and target category +0x60 other than 6. If eligible, it consumes one draw even at zero probability. Starting from zero, source actions 0x3A, 0x0C, 0x44, 0x5D or 0x45 set the base probability to 1. Multiply by 0.15 for targets passing RVA 0x445D0 and by 0.1 for sources failing that predicate whose category is nonzero. Then source action 0x5B or 0x4A sets the base to 1, as does target action 0x54. The predicate accepts creature type integers at +0x64 of 0x65, 0x6B, 0x6C, 0x6D, 0x72, 0x73, 0x74, 0x75, 0x76 or 0x77. RVAs 0x1983EC–0x1984A3 and 0x445D0.

Multiply the base by two raised to ten times the difference between the source and target level fractions, in that order. Cap at 1 and multiply by 0.9. Any type 1 on the target forces the final threshold to zero. Divide the draw by 32,767 in binary32. A result strictly below the threshold sets record +0x40 to 10.0, assigns record +0x18 from RVA 0x44FF0 and emits sound 0x17 before appending the ordinary record. The duration is 1,500 ms for category zero, otherwise 3,000 minus the integer quotient of the unsigned target byte +0x1A8 times 1,500 divided by four. RVAs 0x1984A3–0x198658, 0x3CA60 and 0x44FF0.

## Applying damage

The ordinary record is appended before the consumer runs. Each special kind also goes through that consumer immediately. It resolves the target again and requires a living target. When world +0xB8 is null and the target category is zero, it appends another copy to the hit collector and returns. This can duplicate a record from one producer call. With target +0x7E bit 13 set, the later application gate requires a positive entry in the target's +0x13A4 map whose ID resolves to a category-zero creature. RVAs 0x198677–0x1986D5, 0x195A60–0x195B3E and 0x195CE7–0x195D74.

Kind 3 returns before HP handling. A positive kind 5 record consumes the **recorded magnitude** from each target type 6 entry individually. If an entry is exhausted, its magnitude and remaining time both become zero. This branch also publishes the changed buff entries. For positive ordinary damage the target, and the resolved source if present, must each pass RVA 0x3E310. Allowed category bytes are 0, 1, 3, 5, and 6 except creature type 0x8C, 0x8D or 0x8E. The consumer subtracts the binary32 record magnitude from target binary32 HP, rounds to binary32, and clamps lethal HP to zero before the death path. Zero magnitude preserves HP. Negative magnitude on the ordinary path adds its absolute value and caps at the target's maximum HP helper. The consumer handles reaction duration and vector separately from damage. RVAs 0x195D70–0x196158, 0x3E310 and 0x44DB0.

On an eligible tick with a missing source, positive magnitude of 8, no type 1 modifiers, and an accepted living target at 20 HP, the ordinary record has source ID zero, magnitude 8 and leaves 12 HP if the consumer reaches the damage path. Under the same conditions with a resolved source, a factor of 1, defense of 3, and eligible type 6 magnitudes totaling 2, the original first records kind 5 with magnitude 8, then an ordinary hit of 3. Only the latter subtracts HP. These examples follow the branches above.

## Evidence limits

This is a static contract for the local client pass, its immediate hit construction and the stated consumer branches. Direct hit-routine draws are distinguished from downstream effects. Lethal hits can enter reward handling with further draws, including RVA 0x196A1E. Full death, reward, hostility, equipment presentation, external delivery, floating-point exceptional inputs, frame scheduling and parity with a separate executable remain outside this review. No native playthrough or rendered effect was observed.

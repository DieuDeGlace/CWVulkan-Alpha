## Tail-outside mode and search rerooting

Define P as the following local Boolean: actor `+0x5C` mask `0x40` is clear, list count is unsigned below 30, and the list's final node has ordered squared grid distance from the converted destination strictly greater than radius squared. P is a local mode of this call, not a stored actor mode or a claim about route completeness. [Evidence: `binary/Cube.exe`, RVAs `0x1A8322–0x1A83A8`.]

Rerooting occurs only with P false, D zero, and nearest-node coordinate unequal in any of its three words to the stored integer anchor `+0x141C`. On admission the helper copies the nearest coordinate into the anchor, then writes raw start `+0x1428` as that signed grid triplet scaled by `65536`, without half-cell or half-height offsets. In the ordinary nonnegative-score domain, this retains the first lexicographic key on a score tie. Only a final nonnegative tracker is extracted into the temporary set and erased from the original pending set. The number of attempts is the signed minimum of the original pending count and 70. The original pending set is then cleared and replaced with a copy of the selected keys. [Evidence: `binary/Cube.exe`, RVAs `0x1A840C–0x1A85A5`, signed component comparisons at `0x1A78BA–0x1A78C9` and `0x1A7C45–0x1A7C57`; `decompiled/client/functions/005a6c60.c`, `005a78a0.c`.]

## Direction construction and local state gates

The final target center is rebuilt once more, then current actor raw position is subtracted from it in complete signed 64-bit components. Each difference is converted to binary32 and multiplied by binary32 `1/65536`. Call those unnormalized components dx, dy, dz. Before any length check, the helper writes actor `+0x124` bit 1: set exactly when D is signed below four, actor `+0x5C` bit `0x04` is set, and A is false; otherwise clear. Other bits are preserved. [Evidence: `binary/Cube.exe`, RVAs `0x1A8F08–0x1A90F4`.]

J is then retained true only when its prior lookahead value was true, A is true, actor `+0x5C` bit `0x40` is clear, and unnormalized dz is ordered at or below binary32 one. All other cases clear J, including unordered dz comparison under masked exceptions. The squared length is formed as dy squared plus dx squared, then dz squared, in binary32. An ordered value at or below binary32 `0.001` **or an unordered comparison** returns AL true immediately. This shortcut follows possible counter/reroot/flag writes and entry steering zeroing, but precedes later velocity, object, and `+0x4C/+0x50/+0x54` writes. [Evidence: `binary/Cube.exe`, RVAs `0x1A90F4–0x1A915E`, `0x1A9C74–0x1A9C99`.]

Only squared length ordered greater than one invokes square-root normalization. The binary32 length squared is promoted to binary64 in XMM0, sent through thunk RVA `0x28D9C8` to named import `MSVCR110.dll!_libm_sse2_sqrt_precise`, immediately narrowed to binary32, and used for a binary32 reciprocal. Components are multiplied by that reciprocal; there is no fused operation or binary64 component normalization. Lengths between the small cutoff and one retain unnormalized components. Imported square-root implementation, upper-lane dependencies, and exceptional/control-state behavior are not closed by these callers. [Evidence: `binary/Cube.exe`, RVAs `0x1A9164–0x1A91B7`, original import directory/IAT RVA `0x2FC460`.]

After normalization, ordered positive dz becomes exactly one. Ordered negative dz becomes exactly negative two only if actor `+0x5C` bit `0x02` is set; otherwise its existing value remains. Actor `+0x5C` bit `0x40`, when set, then forces dz to exactly three and reaches the object interaction below. The altered direction is not normalized again. ## Velocity and steering output, elapsed behavior

## Counter producer and scope limits

The creature constructor explicitly initializes `+0x145C` to zero at RVA `0x03BA67`. Setup zeroes it, and this follower zeroes it when D is zero. The follower itself does not add elapsed to it. A later reached world stage at RVA `0x21CCF2`, after its three-axis integration loops, adds the same signed elapsed word to actor `+0x145C` with ordinary 32-bit addition, without a clamp at that store. Thus the follower's 3000 threshold is checked before this later increment in a world invocation, and a same-invocation nearest-zero reset can be followed by an elapsed addition. Reaching that later stage on every external branch is not asserted. [Evidence: `binary/Cube.exe`, RVAs `0x03BA67`, `0x1A9FFE`, `0x1A830C–0x1A831C`, `0x21CC78–0x21CCF8`.]

No random-number or seed access occurs in the inspected follower, its ordinary container operations, terrain predicate, or selector-1/2 stores. The function allocates/frees temporary containers during rerooting and reaches imported square-root math. Its resident terrain/object inputs and route endpoints can originate from random or generated upstream producers, which are not audited here. Supplied setup, clear, map-copy, coordinate-list-production, world fallback, allocator/error, and imported-math services have the specific reached effects described above; their full wider call graphs and all exceptional policies are not claimed closed.
